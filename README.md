# C++ ATM Menu

My first C++ ATM mini-project.

## About

This is a simple ATM menu program created while learning C++.
The user can check their balance, withdraw money, or exit the program.

## Features

- Check balance
- Withdraw money
- Check for insufficient balance
- Exit the ATM

## C++ Concepts Used

- Variables
- cin and cout
- if / else
- switch
- case
- break
- default
- updating variable values

## What I Learned

I learned how to use 'switch' statements together with
'if / else' statements and how to update a variable
when money is withdrawn.
